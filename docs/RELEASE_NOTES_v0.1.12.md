# ぬこIME v0.1.12 (macOS プレビュー)

v0.1.11 からの変更は **「ご確認いただけますと」等の ん＋母音が一発で変換できる**
ようになったことと、**候補パネルで変換スコア・出所が見える**ようになったことが
目玉です。引き続き署名 + 公証済み（Developer ID）の pre-release です。

## 目玉

### ✍️ 「ご確認いただけ」等、語をまたぐ ん＋母音が一発変換に

`gokakuninitadakemasuto`（単一 n）/ `gokakuninnitadake`（nn）どちらで打っても、
**ご確認いただけますと幸いです** のように正しく変換できるようになりました。

- 従来はローマ字の仕様上「ん＋な行」に寄ってしまい、文節をまたぐ ん＋母音の境界
  （ん＋い 等）を拾えず、「互角に似ただけ」のように化けていました。
- 直し方: 文全体で ん＋母音の代替読みも変換し、**文全体の最良スコアで**正しい方を
  選ぶようにしました（単語単体はすでに対応済み、今回は**文**に拡張）。
- あわせて、正当な ん＋な（例 `くりーんな`＝クリーンな）を誤って書き換えてしまう
  リグレッション（「クリーン阿呆で」）も根治し、回帰テストを追加しました。

> これは打ち方の問題でもアポストロフィ回避でもなく、**変換の仕事**です。
> ATOK / Google 日本語入力と同じく、変換側で正しい境界を選びます。

### 🔢 候補パネルで「スコア」と「出所」が見える（既定 OFF）

「なぜこの候補が1位か」を候補ウィンドウ上で見られるようになりました。
いずれも入力メニューのトグルで ON、**表示専用で変換結果・順位は変わりません**。

- **候補にスコアを表示** … 各候補行に変換スコアを併記。小さい等幅数字で、
  **正=緑／負=オレンジ**に色分け（値が大きい＝緑＝優先、が一目で分かる）。
- **候補に出所を表示（学習/個人）** … 自分の履歴・登録から出た候補に淡色で
  「学習」「個人」の印。エンジン既定の候補は無印。
- 何度も選ぶと「学習」印の候補が上位に上がっていく様子が、スコアの数字で
  見えるようになりました。

## 既知の制約
- **macOS のみ / arm64 単独**。変換モデル（~166MB）は手動配置（内容は v0.1.3〜と同一）。
- 使用回数が拮抗する誤学習（例 `そこ` vs `底`）は未対応。「打ち直し＝間違い側を
  下げる」仕組みと文脈学習は次段の課題です。固有名詞・長文はまだ誤変換あり。

## インストール
手順は [`docs/MANUAL.md`](MANUAL.md) / [`docs/RELEASE.md`](RELEASE.md)。既存ユーザーは
アプリ内「🔄 アップデートを確認…」→「今すぐ更新」でも更新できます（完了時に通知）。
更新後は入力ソースを切り替える（ことえり等 → ぬこIME）と確実に反映されます。

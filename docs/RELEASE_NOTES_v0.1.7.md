# ぬこIME v0.1.7 (macOS プレビュー)

v0.1.6 からの主な追加は **Ollama 設定の「本当につながるか」を確認できる手段**です。
引き続き署名 + 公証済み（Developer ID）の pre-release です。

## 目玉

### 🔌 「AI接続テスト」ボタン（設定ウィンドウ）
選んだ provider/model で **実際に AI へ 1 往復 ping して応答が返るか**を確認します。
- 「モデル取得」は一覧が引けるだけ。モデル名が向こう（Ollama サーバー）に無いまま
  （例: `claude-sonnet-5-5` のような他プロバイダ用の名前）でも気づけず、dreaming 実行で
  初めて失敗が分かっていた。接続テストなら **その場で「このモデルは無い」まで分かる**。
- 応答待ちの間も IME が固まらないよう**非同期**で実行（別スレッド + メインキュー復帰）。
- 鍵は入力しただけ（保存前）でもテスト可能。

### 🦙 「モデル取得」が入力中のベースURLで効く
- Ollama のベースURL欄に入力しただけ（ai.toml 保存前）の URL でも、その場で接続して
  モデル一覧を取得できる（`nuko models <provider> --base-url <url>`）。
- `/v1` を付け忘れた入力（例 `http://localhost:11435`）は自動補完。
- モデル取得に 10 秒タイムアウト（死んだ SSH トンネルでも設定窓が固まらない）。
- 「現在のキー(ollama)」は **「キー不要（AI接続テストで確認）」** 表示に（Ollama はキー不要）。

## 既知の制約
- **macOS のみ / arm64 単独**。モデル（~166MB）は手動配置（内容は v0.1.3〜と同一）。
- 一部の固有名詞・長文はまだ誤変換あり（使うほど学習で寄ります）。

# ぬこIME 使い方マニュアル

macOS 向け日本語 IME「ぬこIME」の使い方。v0.1.0(プレビュー)時点。

> **まず知っておくと快適なこと**
> - **ネイティブアプリ(メモ / テキストエディット / Safari / Pages 等)で快適に動きます。**
>   Claude Code・VS Code・Slack などの **Electron/Chromium 系アプリでは、
>   フォーカス文節のハイライトが出ない・候補ポップアップが文字に被る**などの
>   制約があります(アプリ側が IME の描画情報を扱わないため。ぬこIME 側では直せません)。

## 基本の流れ

1. ローマ字を打つ(例: `nihongo`)→ 画面に「にほんご」と下線付きで出る
2. **Space** で漢字変換 → 「日本語」
3. **Enter** で確定

## キーバインド

| キー | 動作 |
|------|------|
| **Space** | 変換 / 候補表示中は次の候補へ |
| **↓ / ↑** | 次候補 / 前候補 |
| **数字 1〜9** | その番号の候補を直接確定(表示中のページ内) |
| **Enter** | 確定 |
| **Escape** | 変換をキャンセル(入力前に戻す) |
| **Backspace** | 1 文字削除 / 変換中なら未変換に戻す |
| **← / →** | **文節フォーカスを移動**(複数文節のとき) |
| **Shift+← / Shift+→** | **文節の区切りを伸縮**(下記) |

### 文節の編集(複数文節に分かれたとき)

長めの文を変換すると複数の文節に分かれます(例:「わたしのなまえ」→「私 の 名前」)。

- **← / →** … 編集したい文節へフォーカスを移す
- **Shift+→** … フォーカス文節の**右端を 1 文字伸ばす**(右隣から 1 文字もらう)
- **Shift+←** … フォーカス文節の**右端を 1 文字縮める**(末尾 1 文字を右隣へ)
- フォーカス文節の候補は **Space / ↑↓ / 数字** で選ぶ

> 区切りを間違えて変換されたとき(例:「ここではきものを」)、Shift+←→ で区切りを直せます。
> ネイティブアプリではフォーカス中の文節がハイライトされ、候補パネル上部にも
> `私 の 【名前】` のように区切りが表示されます。

## ローマ字のコツ ⭐(知っていると詰まらない)

**「ん」を確実に入れたいときは `n` の後にアポストロフィ `'` を打つ。** これが最重要。

| 打ちたい語 | ❌ こう打つと | ✅ 正しい打ち方 |
|---|---|---|
| 範囲(はんい) | `hanni` → はんに | **`han'i`** |
| 個人用(こじんよう) | `kojinyou` → こじにょう | **`kojin'you`** |
| 真夜(しんや) | `shinya` → しにゃ | **`shin'ya`** |
| 本屋(ほんや) | `honya` → ほにゃ | **`hon'ya`** |

理由:`ny` は「にゃ行」、`nn` の後の母音は直前の音と結びつくため。`'`(アポストロフィ)で
「ここで『ん』を切る」と明示できます。これは Google 日本語入力・Mozc 等と同じ標準ルールです。

その他:

- `nn` → ん(例:`konnnichiha` → こんにちは)
- 促音は子音を重ねる(例:`kitte` → きって、`matcha` → まっちゃ)
- 長音符は `-`(例:`me-ru` → めーる)

## 学習について

- **使うほど賢くなります。** 確定した候補の頻度をその場で記録し、次の変換に**即反映**します。
- 学習データは **すべてローカル保存**(`~/Library/Application Support/nuko-ime/learning.json`)。
  **外部に送信しません。テレメトリ・利用データ収集も一切ありません**(しないのが既定)。

## 困ったとき

- **打てない / 変換がおかしい / 挙動が変** → まず **入力ソースを一度ことえり等に切替 → ぬこIME に戻す**。
  これで大半は直ります(macOS が IME を読み直すため)。
- **候補が貧弱(ひらがな/カタカナばかり)** → 変換モデルが未配置の可能性。
  [README のインストール手順](../README.md#インストール)でモデルを配置してください。
- それでも直らない → `/tmp/nuko-ime-debug.log` に動作ログが出ます。
  [Issue](https://github.com/foresthill/nuko-ime/issues) で相談してください。

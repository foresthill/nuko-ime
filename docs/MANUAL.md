# ぬこIME 使い方マニュアル

macOS 向け日本語 IME「ぬこIME」の使い方。

> **まず知っておくと快適なこと**
> - **ネイティブアプリ（メモ / テキストエディット / Safari / Pages 等）で快適に動きます。**
>   Claude Code・VS Code・Slack などの **Electron/Chromium 系アプリでは、
>   フォーカス文節のハイライトが出ない・候補ポップアップが文字に被る**などの
>   制約があります（アプリ側が IME の描画情報を扱わないため。ぬこIME 側では直せません）。

## 基本の流れ

1. ローマ字を打つ（例: `nihongo`）→ 画面に「にほんご」と下線付きで出る
2. **Space** で漢字変換 → 「日本語」
3. **Enter** で確定

## キーバインド

| キー | 動作 |
|------|------|
| **Space** | 変換 / 候補表示中は次の候補へ |
| **↓ / ↑** | 次候補 / 前候補 |
| **Enter** | 確定 |
| **Escape** | 変換をキャンセル（入力前に戻す） |
| **Backspace** | 1 文字削除 / 変換中なら未変換に戻す |
| **← / →** | **文節フォーカスを移動**（複数文節のとき） |
| **Shift+→** | フォーカス文節の**右端を 1 文字伸ばす** |
| **Shift+←** | フォーカス文節の**右端を 1 文字縮める** / **文節を割る**（下記） |
| **Tab** | 辞書に無い語を**その場で単語登録**（下記「単語登録」） |

### ファンクションキー（F6〜F10）— 文字種をその場で変換

入力中（未確定）の文字を、変換せずに**カナ・英数へ直接**変えます。

| キー | 変換先 | 例（`nihongo` と打った状態で） |
|------|--------|------|
| **F6** | ひらがな | にほんご |
| **F7** | 全角カタカナ | ニホンゴ |
| **F8** | 半角カタカナ | ﾆﾎﾝｺﾞ |
| **F9** | 全角英数 | ｎｉｈｏｎｇｏ（連打で大小文字が循環） |
| **F10** | 半角英数 | nihongo（連打で大小文字が循環） |

> **F9 / F10 は「かな」でなく打った生のローマ字**を変換します（`howaito` → ｈｏｗａｉｔｏ / howaito）。
> 固有名詞やURL断片をそのまま英字で入れたいときに便利です。

> **数字キーについて**: 数字（0〜9）は候補選択ではなく、**そのまま入力**されます。
> `Space` で全角（１２３）や漢数字（百二十三）に変換できます。

## 文節の編集（区切りの調整・分割）

長めの文を変換すると複数の文節に分かれます（例:「わたしのなまえ」→「私 の 名前」）。

- **← / →** … 編集したい文節へフォーカスを移す
- **Shift+→** … フォーカス文節の右端を 1 文字**伸ばす**（右隣から 1 文字もらう）
- **Shift+←** … フォーカス文節の右端を 1 文字**縮める**（末尾 1 文字を右隣へ）
- フォーカス文節の候補は **Space / ↑↓** で選ぶ

**1 文節にまとまってしまった語を割る**こともできます。例えば「みのさん」が 1 文節に
なったとき、**Shift+←** を押すと `みのさ｜ん`、もう一度で `みの｜さん` と割れます。
これは辞書に無い語でも機械的に割れるので、区切りを自由に作れます。

> 区切りを間違えて変換されたとき（例:「ここではきものを」）も、Shift+←→ で直せます。
> ネイティブアプリではフォーカス中の文節がハイライトされ、候補パネル上部にも
> `私 の 【名前】` のように区切りが表示されます。

## ローマ字のコツ ⭐（「ん」まわり）

「ん」の後に **や行（や・ゆ・よ）や母音**が続く語は、**`n` を 2 回**打つのがコツです。

| 打ちたい語 | 打ち方 | 補足 |
|---|---|---|
| 引用（いんよう） | **`innyou`** | ん + よう。`inyou` だと「いにょう」 |
| 翻訳（ほんやく） | **`honnyaku`** | ん + やく |
| 金曜日（きんようび） | **`kinnyoubi`** | ん + よう |
| 信用（しんよう） | **`shinnyou`** | ん + よう |
| 範囲（はんい） | **`hanni`** でOK | 下の「ん＋母音」参照 |

覚え方（一貫ルール）:

- **にゃ行は `n` 1 個**: `nyou`→にょう、`shinya`→しにゃ
- **「ん」+ や行は `n` 2 個**: `nnyou`→んよう（引用・翻訳・金曜…）
- **「ん」+ にゃ行は `n` 3 個**: `konnnyaku`→こんにゃく
- **「ん」+ 母音**（範囲=はんい、真意=しんい 等）: **`hanni` / `shinni` とそのまま打って Space**
  すれば大丈夫です。ローマ字では `nn`+母音は直後の音と結びついて「はんに」「しんに」になりますが
  （`onna`→おんな と同じ仕組み）、ぬこIME は変換時に「はんい／しんい」も自動で試すので、
  **範囲・真意はそのまま候補に出ます**（`hanni`→範囲、`shinni`→真意 を実機で確認済み）。
  アポストロフィ（`han'i`）を使う必要はありません。

その他:

- `nn` → ん（例: `konnnichiha` → こんにちは）
- 促音は子音を重ねる（例: `kitte` → きって、`matcha` → まっちゃ）
- 長音符は `-`（例: `me-ru` → めーる）

## 記号・句読点

- **記号を打っても変換中の文は確定しません。** 例えば「にんしきそうい」を変換した後に
  `?` を打つと、「認識相違ありますか？」を**未確定のまま**編集し続けられます（Enter で確定）。
- `?` `!` は打つと**候補**になり、**Space** で `？ / ? / ⁇ / ❓`（`！ / ! / ‼ / ❗`）を選べます。
- `,`→`、`、`.`→`。`、`/`→`・`、`(`→`（` など ASCII 記号は全角になります。
- `かっこ` と打って変換すると `（）「」【】` 等が出ます。

## 数字

- 数字はそのまま入力されます。
- **Space** で変換すると **全角（１２３）・漢数字（百二十三）** を選べます。

## 絵文字・顔文字

**読みで絵文字が引けます**（変換候補に出ます）。例:

- 表情: `にこ`→☺️ / `えがお`→😊 / `わーい`→☺️🙌 / `かなしい`→😢 / `わらう`→😂 / `ぴえん`→🥺
- 手・ハート: `ありがとう`→🙏 / `いいね`→👍 / `はーと`→❤️ / `きらきら`→✨
- 動物・食: `ねこ`→🐈 / `いぬ`→🐕 / `すし`→🍣 / `ぱんだ`→🐼
- 天気・物: `はれ`→☀️ / `すまほ`→📱 / `おめでとう`→🎉
- 記号: `やじるし`→→ / `くろまる`→● / `ちぇっく`→✓
- 顔文字（AA）: `かおもじ`→(^_^) など

## 単語登録（マイ辞書）

変換候補に出ない語（人名・固有名詞・専門語・独自の略記など）は、**マイ辞書**に登録できます。
**登録した語はその読みで必ず変換 1 位**に出ます（よく使うかな候補より優先）。登録の方法は 3 つ:

### ① 📚 マイ辞書ウィンドウ（一覧・追加・編集・削除）

入力ソースメニュー →「**📚 マイ辞書（単語の登録・一覧）…**」で専用ウィンドウが開きます。

- **追加**: 「読み」と「表層（変換後の語）」を入力して「辞書に登録」
- **一覧 / 編集 / 削除**: 登録済みの語を選んで、その場で修正・削除
- 例: 読み `け` → 表層 `家` を登録すると、文中でも `け` が `家` に変換されます

### ② メニュー「単語登録:「A」→「B」」（Tab）

直近 2 回の確定から「1 つ前の読み → 直前の語」を自動で提案します。
間違えて直した直後に使うと便利です。

- 例:『こまや → 駒屋（誤）』の後に『こまたに → 駒谷（正）』と打つと、
  メニューに「単語登録:「こまや」→「駒谷」」が出ます。**Tab** でも開けます。

### ③ 入力中に「📝「<読み>」を単語登録…」

変換中（未確定）にメニューを開くと、**いま入力中の読みが入った状態**で登録画面が開きます。
読みを打ち直す手間なく、表層だけ入れれば登録できます。

## 入力ソースメニュー（メニューバーのぬこIMEアイコン）

メニューバーの入力メニューから、学習や設定の画面を開けます。

**学習・辞書**
- 📝「<読み>」を単語登録…（入力中のみ表示）
- 単語登録:「A」→「B」（直近の確定から提案）
- 📚 マイ辞書（単語の登録・一覧）…
- 学習状況を見る…
- 学習を今すぐ研ぎ直す
- 🤖 AIで学習を研ぎ直す（BYOK）
- ⚙️ BYOK 設定…（APIキー/モデル）
- 📊 AI ログを見る…（コスト/送受信）

**変換設定（トグル・既定すべて OFF）**
- 旧字体モード（國/體/學…）… 旧字体の候補を下位に追加
- 候補にスコアを表示 … 各候補の内部スコアを併記（学習の効き具合が見える）
- 候補に出所を表示（学習/個人）… 「学習」「個人」の印を淡色で添える

> これら 3 つは**表示・変換結果に影響する任意機能**で、既定は OFF。
> スコア表示・出所表示は**順位や変換結果を変えません**（見るだけ）。

**情報**
- 🔄 アップデートを確認…
- ぬこIME について…

## 学習について

**使うほど賢くなります。** すべてローカルで完結し、**外部送信・テレメトリは一切ありません**。

- **頻度学習**（常時ON）: 確定した候補を記録し、次の変換に即反映。よく使う語ほど上位に。
- **訂正学習**: 既定でない候補を選ぶ・打ち直す・単語登録する、を「訂正」として学習し、
  文脈の中でも順位が直ります（例:「まつや」で 松谷 を選ぶと「まつやさんと…」でも 松谷 に）。
  **さらに賢くしたいときは「観察ログ」をON**（既定OFF＝プライバシー重視。下の `nuko learn on`）。
- **単語登録**: マイ辞書に登録した語はその読みで**常に 1 位**（上記「単語登録」参照）。
- **自動反映**: 確定のたびに自動で学び直すので、手動操作は不要です

> **間違って覚えた変換を取り消したい**ときは、📚 マイ辞書ウィンドウ下部の
> 「**学習を忘れる（読み→表層）**」に、忘れさせたい「読み」と「表層」を入れてください
> （例: `けん → 険` を忘れる）。単語登録の削除とは別物で、こちらは
> **自動で覚えた変換**を取り消します。

学習状況は CLI で見られます:

```bash
nuko learn            # 学習状況の表示
nuko learn on / off   # 観察ログのオプトイン ON/OFF（既定: OFF＝記録しない）
nuko learn relearn    # 観察ログから訂正選好を作り直す
nuko learn forget いって --surface 言って  # 誤学習した変換を忘れる
```

> **観察ログ（`observations.jsonl`）は既定 OFF**。ON にして初めて確定が記録され、
> 訂正選好をより精密に作れます。保存は完全にローカル・外部送信なしです。

入力ソースメニューの「**学習を今すぐ研ぎ直す**」でも同じことができます。

保存場所（すべてローカル）: `~/Library/Application Support/nuko-ime/`
（`learning.json` 頻度 / `observations.jsonl` 観察 / `corrections.toml` 訂正 / `user_dict.json` 単語登録）

## 困ったとき

- **打てない / 変換がおかしい / 反映されない** → まず **入力ソースを一度ことえり等に切替 → ぬこIME に戻す**。
  これで大半は直ります（macOS が IME を読み直すため）。
- **候補が貧弱（ひらがな/カタカナばかり）** → 変換モデルが未配置の可能性。
  [README のインストール手順](../README.md#インストール)でモデルを配置してください。
- それでも直らない → `/tmp/nuko-ime-debug.log` に動作ログが出ます。
  [Issue](https://github.com/foresthill/nuko-ime/issues) で相談してください。

## 現時点の制限

- **macOS 専用**（Windows / Linux は計画中、未実装）
- **署名 + 公証済み（Developer ID）**（Gatekeeper 警告なしで導入可。手順は [README](../README.md#インストール) 参照）
- Electron/Chromium 系アプリではハイライト・ポップアップ位置に制約

> **学習は 3 層**で動きます:
> ① 頻度学習（確定を即反映）② 訂正学習（決定論的な選好）はすぐ有効、
> ③ **AI 学習最適化（BYOK dreaming）はオプトイン**（メニュー「🤖 AIで学習を研ぎ直す」。
> 自分の API キーが必要・ローカル保存。使わなくても ①② だけで賢くなります）。

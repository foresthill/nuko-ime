# ぬこIME 使い方マニュアル

macOS 向け日本語 IME「ぬこIME」の使い方。

> **まず知っておくと快適なこと**
> - **ネイティブアプリ（メモ / テキストエディット / Safari / Pages 等）で快適に動きます。**
>   Claude Code・VS Code・Slack などの **Electron/Chromium 系アプリでは、
>   フォーカス文節のハイライトが出ない・候補ポップアップが文字に被る**などの
>   制約があります（アプリ側が IME の描画情報を扱わないため。ぬこIME 側では直せません）。

## 基本の流れ

1. ローマ字を打つ（例: `nihongo`）→ 画面に「にほんご」と下線付きで出る
2. **Space** で漢字変換 → 「日本語」
3. **Enter** で確定

## キーバインド

| キー | 動作 |
|------|------|
| **Space** | 変換 / 候補表示中は次の候補へ |
| **↓ / ↑** | 次候補 / 前候補 |
| **Enter** | 確定 |
| **Escape** | 変換をキャンセル（入力前に戻す） |
| **Backspace** | 1 文字削除 / 変換中なら未変換に戻す |
| **← / →** | **文節フォーカスを移動**（複数文節のとき） |
| **Shift+→** | フォーカス文節の**右端を 1 文字伸ばす** |
| **Shift+←** | フォーカス文節の**右端を 1 文字縮める** / **文節を割る**（下記） |
| **Tab** | 辞書に無い語を**その場で単語登録**して確定（下記） |

> **数字キーについて**: 数字（0〜9）は候補選択ではなく、**そのまま入力**されます。
> `Space` で全角（１２３）や漢数字（百二十三）に変換できます。

## 文節の編集（区切りの調整・分割）

長めの文を変換すると複数の文節に分かれます（例:「わたしのなまえ」→「私 の 名前」）。

- **← / →** … 編集したい文節へフォーカスを移す
- **Shift+→** … フォーカス文節の右端を 1 文字**伸ばす**（右隣から 1 文字もらう）
- **Shift+←** … フォーカス文節の右端を 1 文字**縮める**（末尾 1 文字を右隣へ）
- フォーカス文節の候補は **Space / ↑↓** で選ぶ

**1 文節にまとまってしまった語を割る**こともできます。例えば「みのさん」が 1 文節に
なったとき、**Shift+←** を押すと `みのさ｜ん`、もう一度で `みの｜さん` と割れます。
これは辞書に無い語でも機械的に割れるので、区切りを自由に作れます。

> 区切りを間違えて変換されたとき（例:「ここではきものを」）も、Shift+←→ で直せます。
> ネイティブアプリではフォーカス中の文節がハイライトされ、候補パネル上部にも
> `私 の 【名前】` のように区切りが表示されます。

## ローマ字のコツ ⭐（「ん」まわり）

「ん」の後に **や行（や・ゆ・よ）や母音**が続く語は、**`n` を 2 回**打つのがコツです。

| 打ちたい語 | 打ち方 | 補足 |
|---|---|---|
| 引用（いんよう） | **`innyou`** | ん + よう。`inyou` だと「いにょう」 |
| 翻訳（ほんやく） | **`honnyaku`** | ん + やく |
| 金曜日（きんようび） | **`kinnyoubi`** | ん + よう |
| 信用（しんよう） | **`shinnyou`** | ん + よう |
| 範囲（はんい） | **`han'i`** または `hanni`→はんに | ん + 母音はアポストロフィが確実 |

覚え方（一貫ルール）:

- **にゃ行は `n` 1 個**: `nyou`→にょう、`shinya`→しにゃ
- **「ん」+ や行は `n` 2 個**: `nnyou`→んよう（引用・翻訳・金曜…）
- **「ん」+ にゃ行は `n` 3 個**: `konnnyaku`→こんにゃく
- **「ん」+ 母音**: `n` の後にアポストロフィ `'`（`han'i`→はんい）。`nn`+母音は直後の音と
  結びつく（`kanna`→かんな、`onna`→おんな）ため

その他:

- `nn` → ん（例: `konnnichiha` → こんにちは）
- 促音は子音を重ねる（例: `kitte` → きって、`matcha` → まっちゃ）
- 長音符は `-`（例: `me-ru` → めーる）

## 記号・句読点

- **記号を打っても変換中の文は確定しません。** 例えば「にんしきそうい」を変換した後に
  `?` を打つと、「認識相違ありますか？」を**未確定のまま**編集し続けられます（Enter で確定）。
- `?` `!` は打つと**候補**になり、**Space** で `？ / ? / ⁇ / ❓`（`！ / ! / ‼ / ❗`）を選べます。
- `,`→`、`、`.`→`。`、`/`→`・`、`(`→`（` など ASCII 記号は全角になります。
- `かっこ` と打って変換すると `（）「」【】` 等が出ます。

## 数字

- 数字はそのまま入力されます。
- **Space** で変換すると **全角（１２３）・漢数字（百二十三）** を選べます。

## 絵文字・顔文字

**読みで絵文字が引けます**（変換候補に出ます）。例:

- 表情: `にこ`→☺️ / `えがお`→😊 / `わーい`→☺️🙌 / `かなしい`→😢 / `わらう`→😂 / `ぴえん`→🥺
- 手・ハート: `ありがとう`→🙏 / `いいね`→👍 / `はーと`→❤️ / `きらきら`→✨
- 動物・食: `ねこ`→🐈 / `いぬ`→🐕 / `すし`→🍣 / `ぱんだ`→🐼
- 天気・物: `はれ`→☀️ / `すまほ`→📱 / `おめでとう`→🎉
- 記号: `やじるし`→→ / `くろまる`→● / `ちぇっく`→✓
- 顔文字（AA）: `かおもじ`→(^_^) など

## 単語登録（Tab）

変換候補に無い語（人名・固有名詞など）は、その場で登録できます。

1. 読みを打って変換する
2. 候補ウィンドウで目的の語が無ければ、**Tab** を押す
3. 表示された登録候補を確定 → 以降その読みで一番に出ます

## 学習について

**使うほど賢くなります。** すべてローカルで完結し、**外部送信・テレメトリは一切ありません**。

- **頻度学習**: 確定した候補を記録し、次の変換に即反映
- **訂正学習**: 既定でない候補を選ぶ・打ち直す・単語登録する、を「訂正」として学習し、
  文脈の中でも順位が直ります（例:「まつや」で 松谷 を選ぶと「まつやさんと…」でも 松谷 に）
- **自動反映**: 確定のたびに自動で学び直すので、手動操作は不要です

学習状況は CLI で見られます:

```bash
nuko learn          # 学習状況の表示
nuko learn on/off   # 観察ログの有効/無効（既定: 有効）
nuko learn relearn  # 観察ログから訂正選好を作り直す
```

入力ソースメニューの「**学習を今すぐ研ぎ直す**」でも同じことができます。

保存場所（すべてローカル）: `~/Library/Application Support/nuko-ime/`
（`learning.json` 頻度 / `observations.jsonl` 観察 / `corrections.toml` 訂正 / `user_dict.json` 単語登録）

## 困ったとき

- **打てない / 変換がおかしい / 反映されない** → まず **入力ソースを一度ことえり等に切替 → ぬこIME に戻す**。
  これで大半は直ります（macOS が IME を読み直すため）。
- **候補が貧弱（ひらがな/カタカナばかり）** → 変換モデルが未配置の可能性。
  [README のインストール手順](../README.md#インストール)でモデルを配置してください。
- それでも直らない → `/tmp/nuko-ime-debug.log` に動作ログが出ます。
  [Issue](https://github.com/foresthill/nuko-ime/issues) で相談してください。

# ぬこIME v0.1.6 (macOS プレビュー)

v0.1.5 からの主な追加は**新アイコン・アプリ内アップデートの操作ボタン・Ollama 対応**です。
引き続き署名 + 公証済み（Developer ID）の pre-release です。

## 目玉

### 🐈 新アイコン
- アプリアイコン（白猫 + 頬に「あ」）を追加。Finder / システム設定の入力ソースに表示。
- メニューバー/入力モードのアイコンを「あ / A ＋ 猫耳」に刷新（モード表示はそのまま）。

### ⬆️ アプリ内アップデートに操作ボタン
- 「🔄 アップデートを確認…」の結果パネルに **「リリースページを開く」「今すぐ更新」** ボタンを追加。
  - 「今すぐ更新」= `nuko update --apply`（ダウンロード→置換→再起動）。
  - ※ 反映には更新後に【入力ソースを一度切替えて戻す】か再ログインが必要です。

### 🦙 Ollama 対応（AI 学習 / dreaming）
- dreaming のバックエンドに **Ollama**（OpenAI 互換）を追加。ローカルも、**自社サーバーを SSH トンネル**経由でも使える。
- 設定ウィンドウにプロバイダ「Ollama」と **ベースURL 欄**（既定 `http://localhost:11434/v1`、自社は `http://localhost:11435/v1` 等）。
- `nuko models ollama` でモデル一覧取得。
- ※ 日本語変換そのものは従来どおり 100% ローカル。AI は dreaming のみ。

## 既知の制約
- **macOS のみ / arm64 単独**。モデル（~166MB）は手動配置（内容は v0.1.3〜と同一）。
- 一部の固有名詞・長文はまだ誤変換あり（使うほど学習で寄ります）。

## インストール
手順は [`docs/MANUAL.md`](MANUAL.md) / [`docs/RELEASE.md`](RELEASE.md)。既存ユーザーは
アプリ内「🔄 アップデートを確認…」→「今すぐ更新」でも更新できます。

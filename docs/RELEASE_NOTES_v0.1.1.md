# ぬこIME v0.1.1 (macOS プレビュー)

libakaza ベースの macOS 向け日本語 IME。v0.1.0 以降の**集中的なドッグフーディング**で、
変換精度・学習・記号/数字/絵文字・アプリ互換性を大きく改善したプレビューです。
**開発者・早期に試したい方向け**の未署名ビルドです。

## v0.1.0 からの主な改善

### 変換・学習
- **文脈の中でも学習が効く**: 「まつや」で松谷を選ぶと「まつやさんと…」の中でも松谷に
- **辞書に無い語・分割される語も学習で出せる**: 「さわれる→触れる」「1もじ→1文字」等
- **確定のたびに自動で学び直す**(手動操作不要。選んだ候補が次から上位に)
- **文節ごとに選んだ候補が追加入力で保持される**

### ローマ字
- **「ん+や/ゆ/よ」が nn で打てる**: 引用=`innyou`→いんよう、翻訳=`honnyaku`→ほんやく、
  金曜=`kinnyoubi`→きんようび、信用=`shinnyou`→しんよう（旧版では打てなかった超頻出語）
- 「かな」キー押下時の半角スペース漏れを修正

### 記号・数字
- **記号を打っても変換中の文が確定しない**（「認識相違ありますか？」を未確定のまま編集）
- **`?` `!` `(` `)` `[` `]` が変換候補に**（Space で `？/?/⁇/❓`、`（/(/「/【` 等を選べる）
- **数字を Space で全角/漢数字に変換**（`123`→`１２３`/`百二十三`）
- **記号が全アプリで入力できる**（Chromium/Electron 系アプリでの取りこぼしを修正）

### 文節編集
- **1 文節にまとまった語を Shift+← で分割**（辞書に無くても機械的に割れる）
- 変換中でない状態から Shift+←→ で文節編集に入れる

### 絵文字・辞書
- **絵文字「一式」を読みで引ける**（`にこ`→☺️、`すし`→🍣、`わーい`→☺️、`ちぇっく`→✅ 等）
- 顔文字・記号・現代頻出語・括弧などを追加

### 単語登録
- **Tab で辞書に無い語をその場で登録**（候補ウィンドウから完結）

### アプリ互換性（Claude Code / VS Code 等 Chromium 系）
- **未確定中の Backspace が効くように修正**
- 記号・数字の取りこぼしを修正

詳しい使い方は [docs/MANUAL.md](https://github.com/foresthill/nuko-ime/blob/main/docs/MANUAL.md) を参照。

## プライバシー方針

- **学習データはすべてローカル保存**（`~/Library/Application Support/nuko-ime/`）。外部送信しない。
- **テレメトリ・利用データ収集は一切なし。しないのが既定**。

## 対応状況（正直に）

- ✅ **macOS のみ**（Apple Silicon / Intel。macOS 13+ を想定）
- ⏳ Windows / Linux は設計上の想定はあるが**未実装**
- ⏳ AI/BYOK 学習は**未実装**（頻度学習＋決定論的な訂正学習まで）
- ⚠️ **未署名**。Gatekeeper の警告が出るので下記手順で許可が必要
- ℹ️ Chromium/Electron 系アプリでは、フォーカス文節のハイライト・候補パネル位置に
  なお一部制約があります（アプリ側が IME の描画情報を扱わないため）

## インストール

**1. アプリを入れる**

1. `NukoIME-v0.1.1-macos.zip` を展開し、`NukoIME.app` を `~/Library/Input Methods/` に置く
2. 未署名のため、Finder で `NukoIME.app` を**右クリック →「開く」**、または
   **システム設定 → プライバシーとセキュリティ**で「このまま開く」を許可
3. ログアウト → ログイン（初回のみ、入力メソッド登録のため）

**2. 変換モデルを入れる**（これが無いと変換品質が大きく落ちます）

```bash
mkdir -p "$HOME/Library/Application Support/nuko-ime"
tar -xzf nuko-ime-model-v0.1.1.tar.gz -C "$HOME/Library/Application Support/nuko-ime/"
# → ~/Library/Application Support/nuko-ime/akaza-model/ に6ファイル + NOTICE が展開される
```

**3. 入力ソースに追加**

システム設定 → キーボード → 入力ソース → 「+」→ 日本語 →「ぬこIME」を追加。

> **困ったとき**: 打てない/挙動が変なときは、まず**入力ソースを一度ことえり等に切替 →
> ぬこIME に戻す**（macOS が IME を読み直します）。

# ぬこIME v0.1.14 (macOS プレビュー)

v0.1.13 からの更新です。目玉は **平仮名ライブ変換**（確定前に推測変換を inline 表示）と、
**手動スコア調整（`⌥←→`）の controller 配線が完了**して実機で効くようになったこと。
加えて **文脈つき候補学習**、スコア調整まわりの実機フィードバック修正、開発者向けに
**文節境界（区切り）の精度評価**を追加しました。引き続き署名 + 公証済み（Developer ID）の
pre-release です。

## 目玉

### 🎹 平仮名ライブ変換（確定前に推測を inline 表示）

- 打鍵中から確定前の推測変換を下線付きで表示します（ことえり／Google 日本語入力と同様、
  opt-in）（#239）。
- **WYSIWYG 原則**：Enter で確定すると、**見えているプレビューがそのまま**入ります
  （「かねちゃん」が「カネちゃん」に化ける等を根治）。
- 長文入力時の打鍵ラグを、読み長の上限を入れて解消しました（#242）。

### 🎚 手動スコア調整が実機で効くように（`⌥←→`）＋ スコア編集モード

- v0.1.13 で「エンジン側のみ実装・キー配線は次段」としていた **`⌥←→` による候補スコアの
  手動微調整が、controller まで配線されて実機で動く**ようになりました（`⌥→` 上げ／`⌥←` 下げ）（#238）。
- **スコア編集モード**：候補パネルでスコアを**数値で直接指定**できます（#241）。
- 調整幅はクランプ付き（教える・訂正の階層を壊さない範囲）。flat / segmented の両経路に適用。

### 🧠 文脈つき候補学習

- **直前の文節**で選好を分ける多軸学習（例：「どうしようかな」→「どう仕様かな」になる類を
  文脈ごとに学習）（#240）。独立ストアに保存し、訂正の階層は壊しません。

## 修正・調整（#228 実機フィードバック）

- **スコア調整（`⌥←→` / `⇧↑`）で、手動で切り直した文節区切りが元に戻る不具合を修正**（#244）。
- **`⌃⏎`＝降格 の手動トリガーを廃止**：効きが分かりにくかったため（降格は打ち直し訂正等で
  自動的に効きます）（#243）。

## 開発者向け：変換精度ベンチ（区切り軸）

- **文節境界（区切り）の精度評価**を `nuko eval --segment` に追加（境界 Precision/Recall/F1 ＋
  文完全一致率）。「どの漢字か（表層）」とは別軸で「どこで切るか」を測れます（#245, #246, #247）。
- 純粋関数は CI でテスト済み。これは開発ツールで、本リリースの `.app` の変換結果には影響しません。

## 既知の制約

- **macOS のみ / arm64 単独**。変換モデル（~166MB）は手動配置（内容は v0.1.3〜と同一で、
  本リリースでも**再生成していません**）。
- Windows / Linux は**将来対応予定**。
- 文脈に依存する誤学習（使用回数が拮抗するケース）や、固有名詞・長文の誤変換はまだ残ります。
- 文節区切りは早口言葉など曖昧な文で外すことがあります（言語モデルの限界。詳細は
  `claudedocs/2026-11-27-segmentation-eval-findings.md`）。

## インストール

手順は [`docs/MANUAL.md`](MANUAL.md) / [`docs/RELEASE.md`](RELEASE.md)。既存ユーザーは
アプリ内「🔄 アップデートを確認…」→「今すぐ更新」でも更新できます（完了時に通知）。
更新後は入力ソースを切り替える（ことえり等 → ぬこIME）と確実に反映されます。

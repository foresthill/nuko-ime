# ぬこIME v0.1.13 (macOS プレビュー)

v0.1.12 からの大きめの更新です。**学習が「確定した候補を確実に・暴走せず1位にする」**
方向で作り直され（王冠モデル／降格／打ち直し訂正）、**候補の質**（機械生成の疑似語を
沈めるキュレーション）と、**マイ辞書まわりの使い勝手**が良くなりました。
引き続き署名 + 公証済み（Developer ID）の pre-release です。

## 目玉

### 🎓 学習が安定して「選んだ候補が1位に来る」ように

- **王冠モデル**で確定ブーストの暴走（値が際限なく膨らんで戻らない）を根治。
  「最後に確定した1つ」だけが上限付きで最上位に来る形にしました（#219）。
- **降格機構**：間違い側のスコアを下げられるようになり、追い越しブーストの悪循環を
  断ちました（#217）。
- **打ち直し訂正を常時 ON で捕捉**：同じ読みで打ち直した「正しい方」を、観察ログの
  ON/OFF に関係なく確実に1位へ（#211, #212）。
- **学習の強さ（学習モード）選択**の土台と、選択候補を確実にトップへ上げる追い越し（#201, #219）。
- **文中でも**単語登録・学習が勝つように（Layer0 頻度を文節変換にも適用）（#208）。
- 超高速確定時の「学習が全消え」になる問題をデバウンスで修正（#218）。

### 🧹 候補の質

- **候補キュレーション層**：libakaza が返す「読みの別表記（かな/カナ/半角）」などの
  機械生成の疑似語を、実語より下へ沈めます（外来語カタカナが答えのときは温存）（#223）。
  これはエンジン（アプリ本体）に入るので、本リリースの `.app` に含まれます。
- **記号の代表1つ**を候補2位へ引き上げ、登録なしで1ページ目に出るように（#204）。

### 🗂 マイ辞書・UI

- **マイ辞書を独立ウィンドウに再設計**（追加/編集/削除を同一動線、BYOK 設定から分離）（#205, #206, #207）。
- 入力中に「📝「&lt;読み&gt;」を単語登録…」で**読みを事前入力**して登録（#203）。
- **候補ウィンドウに操作ヒントを常時表示**：順位を上げる/下げる確定キーを淡色で表示。
  表記はプラットフォーム別（macOS=`⇧⏎`/`⌃⏎`、将来の Windows/Linux=`Shift+Enter`/`Ctrl+Enter`）（#227/#233）。
- **Shift+Enter=教える / Ctrl+Enter=降格** ＋ 学習モード選択 UI（#220）。
- **日付フォーマット選好を学習**：選んだ形式（`yyyy/mm/dd` 等）を上位に。日付そのものは
  固定しない（翌日に古い日付が出ない）（#215, #216）。
- dreaming 実行履歴ログ＋ビューア（何がどう学習へ反映されたか）（#210）。

### 🧪 開発者向け：変換精度ベンチ／モデルパイプライン

- **Golden Set による精度測定**（Top-1 / Top-3 / Top-5 / MRR / Lexical Purity@5）を
  `nuko eval` で測れるように（#225）。
- **Mozc OSS 辞書の語彙ブレンド**の仕組みを model-pipeline に追加（rare 語彙の被覆を
  実測で改善）（#226）。⚠️ これは**モデル生成パイプライン側の機能**です。本リリースで
  配布する変換モデル（下記）は**再生成していない＝従来どおり**なので、ブレンドの効果を
  得るにはローカルで `make all` によるモデル再生成が必要です。

## 安定性・品質

- panic を `panic.log` に自己記録（release ビルドでも `file:line` が残る）（#202）。
- `smoke-test.sh` の手動 `open` を除去（`install.sh` の「open 禁止」と整合）（#221）。
- コメントとコードの乖離を防ぐ規律＋誤記修正（#213）。
- CI Documentation ジョブの rustdoc エラーを修正（本リリースで main を緑化）。

## 既知の制約
- **macOS のみ / arm64 単独**。変換モデル（~166MB）は手動配置（内容は v0.1.3〜と同一）。
- Windows / Linux は**将来対応予定**（操作ヒントの表記ロジックは用意済みだが、まだ
  それらのフロントエンドは存在しません）。
- スコア微調整（`⌥←→`）はエンジン側のみ実装済みで、キー配線（controller）は次段。
- 文脈に依存する誤学習（使用回数が拮抗するケース）はまだ残ります。固有名詞・長文も誤変換あり。

## インストール
手順は [`docs/MANUAL.md`](MANUAL.md) / [`docs/RELEASE.md`](RELEASE.md)。既存ユーザーは
アプリ内「🔄 アップデートを確認…」→「今すぐ更新」でも更新できます（完了時に通知）。
更新後は入力ソースを切り替える（ことえり等 → ぬこIME）と確実に反映されます。

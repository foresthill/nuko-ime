# ぬこIME v0.1.3 (macOS プレビュー)

libakaza ベースの macOS 向け日本語 IME。v0.1.1 以降の集中的なドッグフーディングで、
**変換モデルのフル訓練・文節まわりの学習・AI dreaming の実稼働**など大きく前進した
プレビューです。**開発者・早期に試したい方向け**の未署名ビルドです。

> v0.1.2 は内部版（未公開）で、その内容も本リリースに含みます。

## 目玉

### 🎯 フルモデルで素の変換品質が向上
言語モデル（unigram/bigram/skip-bigram）を **min（epochs 最大50）→ full（最大10000）** で
再訓練。min では埋もれていた常用語が**学習に頼らず素で正しく1位**に出ます。

| 入力 | 以前 | **v0.1.3** |
|---|---|---|
| たいかく | た以下く | **体格** |
| せいかつ | 背以下つ | **生活** |
| だいじょうぶ | 台じょうぶ | **大丈夫** |

### 🔢 助数詞をルールエンジンで網羅
「本/杯/匹…×数×音便」を**規則から決定論生成**。`いっぽん→一本`・`さんぼん→三本`・
`じゅっぽん→十本`・`いっぱい→一杯`・`さんびき→三匹`・`じゅっかい→十回` 等が出ます。
個別登録ではなくルールエンジン。

### 🧩 文節まわりの学習（2軸）
- **文節の切り方の学習（境界）**: 文中で誤分割される名前・複合語を学習で切り直し
  （例: `ざびさんと大阪に…` → `ザビさん` にまとまる）。
- **文節位置の学習（新）**: **Shift+←→ で切り直して確定すると、その切り方を覚えて再適用**。
  使うほど自分の区切りに寄ります。
- **複合語の学習**: `情報公開課` のように単字では学べない語を文脈ごと学習。

### 🌙 AI dreaming（Layer 3）実稼働
`nuko dream --provider openrouter --apply` で、観察履歴を LLM が整理して選好を提案・反映
（on-demand）。API キーは環境変数 `OPENROUTER_API_KEY`、設定は `ai.toml`（平文保存しない）。

### 🧹 誤学習の取消 `nuko learn forget`
効きすぎた学習を取り消し（観察ログごと除去、再学習で戻らない）。

### 🖥️ 学習状況のリッチ画面
メニュー「学習状況を見る…」がスクロール可能に。変換の学習と**文節の切り方の学習**を
カテゴリ分けで表示。

## その他の改善（v0.1.1 以降）
- 記号・数字・絵文字の扱い、Chromium/Electron 系での未確定更新（Backspace 等）の改善
- ローマ字「ん＋や/ゆ/よ」（`innyou`→いんよう 等）
- 変換確定ごとの自動再学習（手動操作不要）

## 既知の制約
- **macOS のみ**／**未署名**（初回は「プライバシーとセキュリティ」で実行許可が必要）
- **ファンクションキー（F6-F10）の文字種変換は非対応**。macOS の IME イベント方式の制約
  （生 NSEvent が必要＝大改修）のため今回は見送り。カタカナ等は **Space 循環**で出せます。
- 一部の固有名詞・長文はまだ誤変換あり（使うほど学習で寄ります）

# ぬこIME v0.1.4 (macOS プレビュー)

libakaza ベースの macOS 向け日本語 IME。v0.1.3 以降、**BYOK/AI dreaming の実アプリ化・
旧字体モード・IMK 方式3移行（F キー対応）・変換まわりの多数の修正**が入った大きめの
プレビューです。**開発者・早期に試したい方向け**の未署名ビルドです。

## 目玉

### 🤖 BYOK（自分の API キー）と AI dreaming をアプリから
- メニューに **BYOK 設定ウィンドウ** を追加。provider／model を選び、API キーは **Keychain 保存**（平文にしない）。
- 「いま使っている provider/model」を実値で表示。AI 呼び出しログ（全文・トークン・USD コスト）をパネルで確認可能。
- メニューから **実 AI dreaming（BYOK）** を実行。実行は **非同期**で、処理中も入力はブロックされません。
- CLI は OpenRouter に加え **Anthropic 直 API** にも対応。

### 🈷️ 旧字体モード
- メニューのトグルで ON/OFF。候補に旧字体版（國／體／學／禮 …）を追加（既定の新字体はそのまま 1 位、旧字体は下位）。
- 旧字体 seed を **25 → 259 字**に拡張（立命館の対照表で検証）。

### ⌨️ IMK 方式3へ移行 ＝ ファンクションキーに対応
- 入力イベント方式を刷新し、**F6/F7/F8（ひらがな・全角カタカナ・半角カタカナ変換）に対応**。
  - v0.1.3 では macOS のイベント方式の制約で見送っていた機能です。
- あわせて「ローマ字で直接打てない読み」の救済を強化（下記）。

### ✍️ 変換まわりの改善
- **「きょう」→今日の日付 / 「いま」→現在時刻** を動的に候補生成。
- 文中で **ん＋母音（単位／範囲／千円 …）** を候補に出す。
- `しんに` のような **ん＋な行**入力で、代替読みの実在語（真意 など）に加え **ひらがな「しんい」自体も候補化**し、**旧字体より上**に表示（ローマ字で直接打てない読みを選べるように）。
- 代替読み由来の候補を選んだときの**学習を入力読みに紐づけ**（一度選べば次回から上位に）。
- 変換確定後に記号・数字を打つと**訂正が巻き戻る不具合**を修正。

### 🧹 学習の健全化
- **日付／時刻は学習しない**ように変更。過去に紛れ込んだ古い日付も自己修復（「きょう→古い日付」を根治）。
- 設定ウィンドウから誤学習を**「忘れる」**（読み＋任意の表層、即反映）。
- 肥大化していた観察ログ（observations.jsonl）を**学習を壊さずに間引き**。

### ⬆️ アプリ内アップデート確認
- メニュー「🔄 アップデートを確認…」を追加（GitHub Releases を確認）。
- **本リリースから結果がパネルに表示されます**（IME では標準モーダルが出ないため自前パネルに統一）。

### 🛠️ 導入まわり
- 再インストール時の入力ソース再登録を、`open` ではなく **`TISRegisterInputSource` ＋ ほぼアトミックな置換**に変更（「選べなくなる」事象の低減）。
  - ※ 稼働中 IME の再インストール後は、**入力ソースの切替**、場合により**再ログイン**が必要なことがあります（macOS の制約）。
- かな／英数キー切替直後の「半角スペース漏れ」を修正。release ビルドのデバッグログ肥大化を修正。

## 既知の制約
- **macOS のみ**／**未署名**（初回は「プライバシーとセキュリティ」で実行許可が必要）。
- モデル（~166MB）は**手動配置**（初回自動 DL は将来対応）。
- 一部の固有名詞・長文はまだ誤変換あり（使うほど学習で寄ります）。
- 再インストール後に日本語が打てなくなった場合は、入力ソースの切替→戻す、それでも駄目なら再ログインで復帰します。

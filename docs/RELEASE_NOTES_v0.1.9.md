# ぬこIME v0.1.9 (macOS プレビュー)

v0.1.7 からの追加は **① 文中の語でも学習が効くようになった変換修正** と
**② AI 接続ステータス表示** の 2 つです（v0.1.8 は未公開のまま v0.1.9 に統合）。
引き続き署名 + 公証済み（Developer ID）の pre-release です。

## 目玉

### ✍️ 文中の語でも「直したら次回勝つ」— 学習修正
「11435の**ほう**」→ `方`、「この**よう**」→ `様` のように、**文の中に現れる語**を
何度選び直しても次に libakaza の既定（法／用）に戻ってしまう問題を修正しました。

- 原因: 複数文節の変換経路が **常時ONの頻度学習（Layer 0）を参照していなかった**
  （単文節では効くのに文中では効かない非対称）。設定不要で効きます。
- 直し方は保守的に **読み完全一致のみ**。関係ない常用語を壊さないよう配慮。
- 実機 libakaza で検証: `ほうがいい` 法→**方** / `こっちのほう` 法→**方** / `このよう` 用→**様**。

> 補足: 一度「間違った方」も確定してしまっていると、まだ僅差で負ける場合があります
> （「打ち直し＝間違いを降格」する仕組みは次の課題）。多くのケースは一度選び直せば次回から直ります。

### 🟢 AI 接続ステータス（設定ウィンドウ）
設定ウィンドウ最上部に **「接続: 🟢 OK / 🔴 未接続」** を表示します。
自社サーバーの Ollama を **SSH トンネル**経由で使うと接続が落ちることがあるため、
dreaming を回す前に「いまつながっているか」が一目で分かるように。

- 疎通チェックは `/v1/models`＝**トークン課金ゼロ**の軽量確認。トンネルが落ちていれば即 🔴。
- 設定ウィンドウを**開いた時に自動チェック** ＋ 右上の「🔄 更新」でいつでも再確認。
- 常駐ポーリングはしない（電池・ノイズ最小）。応答待ちで IME が固まらないよう非同期実行。

役割分担：**接続ステータス**＝端点に届くか（トンネル生存）／**AI接続テスト**（v0.1.7〜）＝
選んだモデルで実際に推論できるか。

## 既知の制約
- **macOS のみ / arm64 単独**。モデル（~166MB）は手動配置（内容は v0.1.3〜と同一）。
- 一部の固有名詞・長文はまだ誤変換あり（使うほど学習で寄ります）。

## インストール
手順は [`docs/MANUAL.md`](MANUAL.md) / [`docs/RELEASE.md`](RELEASE.md)。既存ユーザーは
アプリ内「🔄 アップデートを確認…」→「今すぐ更新」でも更新できます。
更新後は入力ソースを切り替える（ことえり等 → ぬこIME）と確実に反映されます。

# ぬこIME v0.1.2 (macOS プレビュー)

libakaza ベースの macOS 向け日本語 IME。v0.1.1 以降のドッグフーディングで、
**変換モデルをフル訓練（epochs=10000）に刷新**し、常用語の変換品質を一段引き上げた
プレビューです。あわせて文節境界の学習と、誤学習の取消コマンドを追加しました。
**開発者・早期に試したい方向け**の未署名ビルドです。

## v0.1.1 からの主な改善

### 🎯 フルモデルで素の変換品質が向上（目玉）

言語モデル（unigram/bigram/skip-bigram）を **min プロファイル（epochs 最大 50）から
full プロファイル（epochs 最大 10000）で再訓練**。min では上位に埋もれていた常用語が、
**個人学習に頼らず素のモデルで正しく 1 位**に出るようになりました。

| 入力 | v0.1.1 (min) | **v0.1.2 (full)** |
|---|---|---|
| たいかく | た以下く | **体格** |
| せいかつ | 背以下つ | **生活** |
| だいじょうぶ | 台じょうぶ | **大丈夫** |
| メール…だいじょうぶです | …台じょうぶ | **…大丈夫です** |

技術的には、curated コーパスと Wikipedia/青空文庫/CC-100 由来の頻度統計から n-gram の
cost（候補の尤もらしさ）を 10000 回反復学習し、候補順位（k-best）を実際の日本語頻度に
近づけたものです。詳細: [`docs/research/2026-09-engines-and-conversion-quality.md`](research/2026-09-engines-and-conversion-quality.md) §4。

### 🧩 文節の切り方の学習（安全化）

学習した語を**分割境界のヒント**にして、文中で誤分割される名前・複合語を切り直します
（例: 文中の `ざびさんと大阪に…` → `ザビさん` にまとまる）。

- **merge-only 制約**: 隣接文節を「統合」する方向だけに限定。短い学習語で無関係な常用語を
  「分割」して壊す事故（体格→た以下く 等）を防ぐ安全設計。
- 敬称込み文節（まつやさん→松谷さん）の目標表層を候補に注入。接尾は敬称のみに限定。

### 🧹 誤学習の取消 `nuko learn forget`

効きすぎた学習を取り消せるコマンドを追加（観察ログごと消すので再学習で戻りません）。

```
nuko learn forget いって              # その読みの学習を全部忘れる
nuko learn forget いって --surface 言って   # 特定表層だけ忘れる
```

### 🌙 AI 学習基盤（Layer 3 dreaming）の土台

将来の「寝ている間に学習を整理する」AI 機能（#102）の provider 非依存な核を実装
（`nuko dream` の dry-run でプロンプトを確認可能）。実 LLM 連携は今後。

## インストール

未署名ビルドのため、初回は「システム設定 → プライバシーとセキュリティ」から実行許可が
必要です。手順は [`docs/MANUAL.md`](MANUAL.md) 参照。

## 既知の制約

- macOS のみ（Linux/Windows は将来）
- 未署名（Gatekeeper の許可が必要）
- 一部の名前・固有名詞・長文はまだ誤変換あり（学習で寄せられます）
